Application Tracker

Job applications found in your Gmail by a Python program (job_tracker.py), with the status from each company's most recent email. No AI sorts your mail.

Run the program, then load what it writes

1 · ONCE

Turn on 2-Step Verification for your Google account, then create an app password. The program asks for it when it runs (or reads GMAIL_APP_PASSWORD).

2 · CHECK WHAT WOULD BE DOWNLOADED
python gmail_scraper.py --since 2026-10-20 --dry-run

Prints the Gmail search and how many messages match. Nothing is saved.

3 · EVERY TIME YOU WANT AN UPDATE
python job_tracker.py imap --since 2026-10-20 --format json --out applications.json

Change --since to look further back. Add --before for an end date.
